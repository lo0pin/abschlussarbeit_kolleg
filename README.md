About the project

AutoMeasure FleX is a prototype graphical application for
configuring measurement setups and communicating with external
hardware via the CAN bus.

The project covered GUI architecture, CAN communication,
data-rate calculations, validation and error handling,
refactoring and packaging as a standalone application.
